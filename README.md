# Faculdade Teológica Logos

Landing page responsiva desenvolvida utilizando HTML5 e CSS3 para apresentação de uma instituição de ensino teológico.

---

## Objetivo do Projeto

O projeto foi criado com foco em:
- responsividade;
- semântica HTML;
- acessibilidade;
- organização de CSS;
- experiência do usuário.

Além disso, foi realizada uma atividade de curadoria de código com Inteligência Artificial, aplicando validação técnica e refatoração em um componente da interface.

---

## Tecnologias Utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Variáveis CSS
- Responsividade Mobile First

---

## Funcionalidades

- Layout responsivo
- Hero section moderna
- Cards de cursos
- Seção de benefícios
- Formulário de contato
- Navbar responsiva com menu mobile
- Dark mode automático
- Acessibilidade com ARIA

---

## Curadoria de Código com IA

Foi utilizado IA para geração e refatoração do componente de navegação responsiva.

Durante o processo foram realizados:
- análise do código;
- identificação de problemas;
- melhorias de acessibilidade;
- otimizações responsivas;
- refinamento visual;
- validação técnica.

O relatório completo pode ser acessado abaixo:
